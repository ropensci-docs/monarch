# Remove Socials by GitHub handle

Remove Socials by GitHub handle

## Usage

``` r
cocoon_remove(github)
```

## Arguments

- github:

  Character. Github username

## Value

Socials data frame

## Examples

``` r
if (FALSE) { # local_eg()
cocoon_fetch("steffilazerte")
cocoon_remove("steffilazerte")
cocoon_fetch("steffilazerte")
}
```
